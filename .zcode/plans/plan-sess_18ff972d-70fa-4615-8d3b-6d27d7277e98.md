# 方案：将 ruoyi-ui `/client/subscripts` 页面改造为匹配 price.vue 的"方案与功能"对比表

## 一、背景与现状

用户目标：让 ruoyi-ui 中 `/client/subscripts`（订阅套餐管理）页面的展示内容匹配官网 `xmbj-www-ui/app/pages/price.vue` 中"方案与功能"对比表的配置。

### 三处关键代码现状

| 文件 | 作用 | 布局 | 权限 / API |
|---|---|---|---|
| `xmbj-www-ui/app/pages/price.vue` | **官网价格页（要匹配的源）** | 横向对比表：功能为行、套餐为列，4 大分类，布尔值 ✓/—，数值带单位 | 后端 `/api/ponynotes/plans/list` |
| `ruoyi-ui/src/views/client/subscripts/index.vue` | **本次要改的目标页** | 旧版若依 CRUD：每行一个套餐、每列一个属性，搜索表单 20+ 字段，布尔值用文本输入 | `system:plans:*` / `/system/plans` |
| `ruoyi-ui/src/views/xmbj/plans/index.vue` | 同仓库已存在的同类改造（参考样板） | 横向对比表（已实现） | `xmbj:plans:*` / `/xmbj/plans` |

> 注：仓库内无 `client/subscripts/setting/plans` 这样的嵌套目录；"subscripts" 是 "subscriptions" 的简写，目标页实际就是 `client/subscripts/index.vue`，路由 `/client/subscripts` 由 `views/client/integrate.js` 第 51-55 行注册。

### 关键决策（采用推荐项，未答时按推荐处理）
1. **实现方式**：原地改写 `client/subscripts/index.vue` 为横向对比表，**保留其现有 `system:plans:*` 权限和 `/system/plans` 接口**（不切换到 `xmbj/plans`），改动面最小，不影响其他菜单/路由。
2. **渲染细节**：数值/布尔字段一律**数据驱动**渲染（参考 `xmbj/plans/index.vue` 的写法），"页面权限管理"按 `pagePermissionGuestEditors` 动态渲染。

## 二、改动范围

**仅改 1 个文件**：`ruoyi-ui/src/views/client/subscripts/index.vue`

不改：
- `@/api/system/plans.js`（接口不变）
- `views/client/integrate.js`（路由不变）
- `views/xmbj/plans/index.vue`（独立页面，不动）
- `views/workspace/workspace/views/system/plans/index.vue`（另一份相同副本，超出本次范围）

## 三、目标页面要匹配的对比表结构（来自 price.vue "方案与功能"）

表头：`功能 | 套餐1 | 套餐2 | 套餐3 | 套餐4`（套餐名取 `planNameCn || planName`，附 `planCode` 与启用状态 `el-tag`）

价格行：月付 `¥{monthlyPriceYuan}/月`、年付 `¥{yearlyPriceYuan}/年`

**四大分类与功能行**（与 price.vue 一一对应）：

| 分类 | 功能行 | 渲染规则 |
|---|---|---|
| **一、基础** | 页面/块数量 | 静态：所有套餐显示"无限制" |
| | 云存储空间 | `cloudStorageGb` + "兆"（沿用 ruoyi-ui 既有写法；price.vue 用 `formatStorage` 换算 MB/GB/TB，但 sys_plans 字段名是 Gb，这里保持与 xmbj/plans 一致用"兆"，避免单位歧义） |
| | 导入与导出 | 按 `hasInbox`：1→✓(绿 #67C23A)，否则 —(灰 #909399) |
| | 收件箱 | 按 `hasInbox`：✓/— |
| | 多端同步 | 按 `hasMultiDeviceSync`：✓/— |
| | 支持 API | 按 `hasApiSupport`：✓/— |
| | 版本历史 | `versionHistoryDays` + "天" |
| **二、AI功能** | AI对话 | `aiChatCountPerMonth`，0→—，否则 "{n}次/月" |
| | 图片生成 | `aiImageGenerationPerMonth`，0→—，否则 "{n}次/月"（price.vue 用"次/月"，xmbj/plans 用"张/月"；采用 price.vue 的"次/月"以匹配源） |
| **三、共享和协作** | 分享链接 | 按 `hasShareLink`：✓/— |
| | 发布 | 按 `hasPublish`：✓/— |
| | 工作区成员 | `workspaceMemberLimit`，0→—，否则数值（price.vue 仅显数值；xmbj/plans 用 ✓/—。采用 price.vue：显数值） |
| | 协作工作区 | `collaborativeWorkspaceLimit`，0→—，否则 "{n}个" |
| **四、安全与权限管理** | 页面权限管理 | 动态：`pagePermissionGuestEditors` 有值→"{n}个访客编辑"；为空且 `hasSpaceMemberManagement===1`→"仅查看"；否则 — |
| | 空间成员管理 | 按 `hasSpaceMemberManagement`：✓/— |
| | 空间成员分组 | 按 `hasSpaceMemberGrouping`：✓/— |

操作行：每个套餐列底部放"修改""删除"按钮（`v-hasPermi="['system:plans:edit'/'system:plans:remove']"`），与目标页原有权限保持一致。

## 四、具体改造步骤

### 步骤 1：替换 `<template>`
将原"搜索表单 + el-table + 分页 + 弹窗"结构替换为（参照 `xmbj/plans/index.vue` 的结构，权限/接口改为 `system:plans`）：

1. 顶部操作按钮栏（新增/修改/删除/导出 + `right-toolbar`），保留 `v-hasPermi="['system:plans:*']"` 原权限。
2. `el-card` 内一个原生 `<table class="comparison-table">`：
   - 表头一行（功能列 + `v-for="plan in plansList"` 套餐列，`isActive===1` 加 `highlight-column` 高亮类）
   - 价格两行（月付/年付）
   - 4 个分类行（`category-row` + `colspan="100%"`）+ 各分类下的功能行
   - 操作行（每套餐列内"修改/删除"按钮）
3. 保留 `pagination`（`/system/plans/list` 仍分页）。
4. 保留 `el-dialog` 新增/修改表单，**布尔字段从 `el-input` 改为 `el-switch :active-value="1" :inactive-value="0"`**，数值字段保持 `el-input`（与 xmbj/plans 弹窗一致，提升可用性）。

### 步骤 2：精简 `<script>` 的 `data()`
- 删除 `queryParams` 中 20+ 个业务字段（搜索表单已移除），仅保留 `pageNum`、`pageSize`（参考 xmbj/plans 写法）。
- `reset()` 中布尔字段默认值改为 `0`（适配 el-switch）。
- `rules` 布尔字段 trigger 从 `"blur"` 改为 `"change"`（适配 el-switch）。

### 步骤 3：新增 `getUpdateData()` 方法
参照 xmbj/plans/index.vue 第 516-542 行，修改时只提交变更字段（diff `originalForm`），含 `booleanFields` 与 `otherFields` 两个白名单，避免覆盖未改动字段。`handleUpdate` 读取详情后保存 `this.originalForm`。

### 步骤 4：新增 `<style scoped>`
搬运 xmbj/plans/index.vue 第 563-702 行的对比表样式：
- 表头紫蓝渐变 `linear-gradient(135deg, #667eea 0%, #764ba2 100%)`
- 首列 `position: sticky; left: 0` 固定
- 价格行浅渐变、分类行灰底 `#f0f2f5`
- `highlight-column` 启用套餐列黄底 `#fff9e6`
- `el-icon-check`(绿)/`el-icon-minus`(灰) 图标样式

### 步骤 5：自检
- 确认 `import { listPlans, getPlans, delPlans, addPlans, updatePlans } from "@/api/system/plans"` 不变。
- 确认所有 `v-hasPermi` 仍为 `system:plans:*`。
- 确认 `handleExport` 的 url 仍为 `system/plans/export`。
- 确认组件 `name: "Plans"` 不变（路由按文件路径加载，不依赖 name）。

## 六、风险与验证

**风险**：低。仅前端单文件改动；接口、权限、路由、菜单均不变。
**验证方式**（实施后）：
1. 进入 ruoyi-ui 后台 `/client/subscripts` 菜单，确认页面渲染为横向对比表。
2. 对照官网 `/price` 页"方案与功能"表，核对各套餐各功能行的展示一致。
3. 测试"新增""修改"弹窗：布尔字段用 switch、数值用 input，提交后列表刷新正常。
4. 测试"修改只提交变更字段"逻辑（getUpdateData）。
5. 测试启用套餐列高亮、首列横向滚动时固定。
